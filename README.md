\# map-study



地图视觉学习项目。



\## 环境

\- Python 3.10 (conda 环境: map-study)

\- PyTorch 2.6.0+cu124

\- CUDA 12.4

\- GPU: NVIDIA GeForce RTX 4060 Laptop (8GB)



\## 文件说明

\- `check\_env.py`        环境检查脚本

\- `env\_check\_log.txt`   环境检查日志

\- `README.md`           项目说明



\## 快速开始

conda activate map-study
