公式比上一步多了什么在解决什么
式 1 CE = −log(p_t)—（基线）用「给正确类别的概率」当尺子：p_t 大损失小，小损失大

验收记录（三条全过）

  • γ 管难易、α_t 管类别数量，未混淆。
  • 单阶段精度差的主因是训练时类别失衡；Focal Loss 在损失层面把简单背景梯度压到近 0，等价于两阶段 RPN 的物理筛选，却不生成候选框，故既快又准。
  • 位置：Day11 检测分支「class box 输出 p → 拿标注 y 算 p_t → Focal Loss 算总损失 → 反传」，仅训练时存在。

评审中订正的四处

  • 「负类」的正/负是类别名，与数值正负号无关；p 与 1−p 都是 0~1 的概率。
  • 笔误 p_t = 1 − p_t → p_t = 1 − p。
  • α_t 下标 t 与 p_t 同源：按真实类别取对应值，不是时间或样本序号。
  • 用 y 顶替 γ 只是输入不便；压缩再解压（U-Net / FPN）与单阶段高精度无关，是两条不同的轴。

位置澄清（2026-11-17 追问补记）

Day11 流程图是前向 + 评测视角（class box → 框 / 置信度 → 人工标注 → mAP / IoU），没有画训练闭环。「算损失 → 反传」是从 class box 输出 p 处分叉出去、只在训练时执行的另一段计算：按 IoU 分配正负 y → 用 p 与 y 拼出 p_t → 逐格 Focal Loss 求和 → loss.backward() 求梯度 → optimizer.step() 改权重 → 回到前向重复几万轮。
  • Focal Loss 只挂在图 7 的分类子网络（W×H×KA）那一支；框回归子网络（W×H×4A）用单独的回归损失（RetinaNet 为 Smooth L1），两者相加才是总损失。
  • 推理时整段训练线不存在，直接拿 p 过阈值出框。

为什么单阶段也能高精度（边界补充 · 2026-11-17）

  • 病根：单阶段不做候选框筛选，前景 / 背景比可达 1:1000，普通交叉熵下海量易分背景的梯度主导训练。两阶段靠 RPN 把十万级 anchor 筛到一两千候选 + 固定正负比采样，失衡被结构性消掉，反证病根不是网络弱。
  • Focal Loss 在损失层面做等价筛选：样本仍参与前向，只是梯度贡献趋近 0，不必生成候选框，故速度保住、精度拿回。
  • 边界：它修的是主因、不是全部原因。RetinaNet 还依赖 FPN 多尺度、更深 backbone、更长训练与数据增强；且只在「密集检测 + 极端类别失衡」场景收益显著，只作用于分类子网络（W×H×KA），框定位由 Smooth L1 等回归损失负责。

延伸：从追问里补透的知识点

以下是今天逐层追问带出来的理解，按知识点整理（不记提问过程）。

1. p、y、p_t 三者各管什么

  • p：分类子网络对某格「是目标」的输出分数，过 sigmoid 压到 0~1 的概率；训练中一直变。
  • y：标注真值，只有 0 或 1，由人工框与候选框的 IoU 分配得来，不是模型判断的，训练中不变。
  • p_t：模型给「正确那一类」的概率——y=1 取 p，y=0 取 1−p。选哪个分支由 y 决定，不由 p 决定。
  • 拼成一行就是标准二分类交叉熵 −[y·log p + (1−y)·log(1−p)]。
  • 推理时没有 y，不算损失，直接拿 p 过阈值出框。

2. γ 与 α_t：两把正交的旋钮

  • γ 管难易：让所有损失随 γ 变小，但简单样本压到 ≈0 闭嘴、难样本只缩到 0.3~0.6 留着分量——选择性静音，不是一视同仁。γ=0 退回交叉熵。
  • α_t 管数量：按真实类别取固定权重（正类 α、负类 1−α），让稀少类别不被淹没；看类别不看难易。
  • 两轴正交：正负 / 难易是四象限，p_t 大只说明答对且自信，不代表是背景。

3.「负类」的「负」不是负数

正 / 负是 positive / negative class 的类别名：正类 = 目标，负类 = 背景。p 与 1−p 都是 0~1 概率。

4. 总损失为什么是「乘」：逐格求和

  • 一次更新看整张图：L_total = Σ Lᵢ，992 × 0.01 只是 992 个 0.01 相加的简写。
  • 梯度可加，每个格子都推一把，小推力叠起来压过大样本。
  • 关键在 0.01 不是 0：γ 把它压到 0.0001 量级，992 × 0.0001 ≈ 0.1，背景格才真闭嘴。

5. FL(p_t) 是函数记号，不是乘法

FL 是损失名，(p_t) 表示输入是 p_t。γ、α 是事先设好的超参，所以损失值完全由 p_t 决定。

6. 正类多、负类少可能吗

普通分类里可能（猫 80% / 狗 20%），少数类照样用 α_t 加权，公式不变。目标检测里负类 = 背景，目标天然稀疏，且 RetinaNet 对每类各做一次二分类，更极端。

7. 训练到底在训练什么

  • 唯一被改的是权重；结构、γ、α、学习率都是人事先定死的超参。
  • 一轮：前向出 p → 用 y 算 p_t → 算损失 → 求梯度 → 权重各挪一小步，重复几万次。
  • 没人写过「地铁站长什么样」的规则，对应关系是从猜错挨罚里自己长出来、存在权重数值里的。

8. 训练完的成果：泛化与它的边界

  • 认没见过的新图叫泛化，靠全程隔离的测试集验证。
  • 换图例 / 分辨率 / 风格 → 分布偏移，精度会掉，需微调。
  • 「认出地铁站」是视觉模式 ↔ 标签的对应，不会读地名、不懂含义——这道缝正是第二篇论文主题。

9. 名词速记

  • RetinaNet：单阶段检测器 = backbone + FPN + 双子网络 + Focal Loss。
  • FPN：把深浅层特征融合成多尺度（C3–C5 → P3–P5），大目标靠深层语义、小目标靠浅层细节。
  • RPN：两阶段检测里「先筛候选框」那一步；RetinaNet 没有它。
  • 单 / 两阶段：只看有没有先生成候选框，与 U-Net 编码-解码、FPN 多尺度是两条不同的轴。
